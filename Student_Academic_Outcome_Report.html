Section A: Data Preprocessing & Pipeline Flow

The dataset contains demographic, socio-economic, and academic performance metrics. To prepare the raw dataset for feedforward neural network training, the following data processing steps were executed:

  • Dataset Inspection: Assessed target distribution ($N = 4,424$, $36$ features) and confirmed zero missing or null entries across all attributes.
  • Feature & Target Separation: Separated input matrix $X$ ($36$ features) from multi-class categorical target vector $y$ (Dropout, Enrolled, Graduate).
  • Target Encoding: One-hot encoded target outputs into binary indicator vectors: Dropout ➔ [1, 0, 0], Enrolled ➔ [0, 1, 0], Graduate ➔ [0, 0, 1].
  • Stratified Train-Test Split: Applied an $80/20$ stratified split ($N_{ ext{train}} = 3,539$, $N_{ ext{test}} = 885$) to preserve target class proportions across subsets.
  • Feature Standardization: Standardized numerical variables using StandardScaler fitted solely on the training set to eliminate data leakage.

Python Implementation Code (Section A)

import pandas as pd
import numpy as np
from sklearn.model_selection import train_test_split
from sklearn.preprocessing import StandardScaler
from tensorflow.keras.utils import to_categorical

# 1. Load Dataset
df = pd.read_csv('ann-datatset.csv')

# 2. Separate Features and Target
X = df.drop(columns=['Target'])
y_raw = df['Target']

# 3. Target Encoding (One-Hot)
target_map = {'Dropout': 0, 'Enrolled': 1, 'Graduate': 2}
y_encoded = to_categorical(y_raw.map(target_map))

# 4. Stratified Train-Test Split (80% Train, 20% Test)
X_train, X_test, y_train, y_test = train_test_split(
    X, y_encoded, test_size=0.20, random_state=42, stratify=y_raw
)

# 5. Feature Scaling (StandardScaler)
scaler = StandardScaler()
X_train_scaled = scaler.fit_transform(X_train)
X_test_scaled = scaler.transform(X_test)

Section C: Neural Network Modeling

A multi-layer feedforward neural network was designed using Keras. Structural regularization (Dropout) was integrated to prevent overfitting and guarantee strong generalization on unseen test data.

Model Structural Justifications:

  • Input Layer: 36 standardized numerical features.
  • Hidden Layer 1: 64 Neurons with ReLU activation and a $20\%$ Dropout layer.
  • Hidden Layer 2: 32 Neurons with ReLU activation and a $10\%$ Dropout layer.
  • Output Layer: 3 Neurons with Softmax activation outputting normalized class probability distributions.
  • Optimization & Loss: Compiled with Categorical Cross-Entropy loss and the Adam optimizer.

Python Training Code (Section C)

import tensorflow as tf
from tensorflow.keras.models import Sequential
from tensorflow.keras.layers import Dense, Dropout

# 1. Model Architecture Setup
model = Sequential([
    Dense(64, activation='relu', input_shape=(X_train_scaled.shape[1],), name="Hidden_Layer_1"),
    Dropout(0.20, name="Dropout_1"),
    Dense(32, activation='relu', name="Hidden_Layer_2"),
    Dropout(0.10, name="Dropout_2"),
    Dense(3, activation='softmax', name="Output_Layer")
])

# 2. Model Compilation
model.compile(
    optimizer='adam',
    loss='categorical_crossentropy',
    metrics=['accuracy']
)

# 3. Model Training
history = model.fit(
    X_train_scaled, y_train,
    epochs=50,
    batch_size=32,
    validation_split=0.15,
    verbose=1
)

Python Evaluation Code (Section D)

import numpy as np
from sklearn.metrics import classification_report, confusion_matrix, accuracy_score, f1_score

# 1. Predictions
y_pred_probs = model.predict(X_test_scaled)

# 3. Print Full Classification Report
labels = ['Dropout', 'Enrolled', 'Graduate']
print(classification_report(y_true_classes, y_pred_classes, target_names=labels, digits=3))
