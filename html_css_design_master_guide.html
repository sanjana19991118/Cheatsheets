HTML, CSS & UI Design Standards

Comprehensive Master Guide: Layouts, Color Themes, Typography Specs & Resources

1. Core HTML & CSS Basics
  • Semantic HTML Structure: Utilize native semantic layout elements (<header>, <main>, <section>, <nav>, <aside>, <footer>) rather than non-semantic <div> wrappers to ensure high accessibility and predictable document architecture.
  • The CSS Box Model: Understand the structure of every rendered element: Content → Padding → Border → Margin. Enforce border-box sizing globally via box-sizing: border-box so explicit width and height properties include padding and borders without overflowing bounds.
  • Modern Layout Engines: Combine CSS Grid for macro-level layouts (dashboard panels, kanban column systems, grid cards) with CSS Flexbox for micro-level alignments (navbar content, icon-text alignment, button groups).

4. Implementation Guidelines
  • Design Tokens & CSS Variables: Define system values inside the :root selector (e.g., --color-bg-primary, --spacing-md, --radius-lg). Toggling light/dark themes will require updating root variables rather than duplicate component classes.
  • Interactive Affordances: Always provide transition feedback on hover, focus, and active states (e.g., transition: background-color 0.2s ease, transform 0.1s ease).
  • Depth & Elevation (Box Shadow): Indicate interactive layers using shadow scales:
    • Cards/Containers: box-shadow: 0 1px 2px 0 rgba(0, 0, 0, 0.05);
    • Modals/Dragging Items: box-shadow: 0 20px 25px -5px rgba(0, 0, 0, 0.1);
