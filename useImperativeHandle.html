React Hook

useImperativeHandle

Customise what a parent sees when it holds a ref to your component

React 16.8+ Requires forwardRef (< React 19) 5-min review
The big idea
🏛️
Think of it as a reception desk. The parent can't walk into the back office (the raw DOM node). Instead it talks to the desk — and you decide exactly which services the desk offers: focus(), reset(), play()…
How the ref flows
Parent
creates ref
──ref──▶
forwardRef + useImperativeHandle
intercepts & replaces
──▶
{ focus, reset… }
parent sees this
╳
<input> DOM node
hidden from parent
Anatomy of the hook
useImperativeHandle(ref, () => ({
  focus() { inputRef.current.focus(); },
  reset() { inputRef.current.value = ''; },
}), [/* deps */]);
① ref
The forwarded ref coming from the parent. Received as the second arg of forwardRef.
② factory function
Returns the object the parent sees. Runs on mount and when deps change.
③ deps array
Like useEffect — omit to re-run every render, or list values the factory closes over.
⚠ Always pair with forwardRef (React < 19) — without it, ref is null inside the child and nothing is exposed.
Minimal complete example
Child — FancyInput.jsx
import { forwardRef, useImperativeHandle, useRef } from 'react';

const FancyInput = forwardRef((props, ref) => {
  const inputRef = useRef(null);

  // ← only these two methods leak out
  useImperativeHandle(ref, () => ({
    focus() { inputRef.current.focus(); },
    clear() { inputRef.current.value = ''; },
  }));

  return <input ref={inputRef} {...props} />;
});

export default FancyInput;
Parent — Form.jsx
import { useRef } from 'react';
import FancyInput from './FancyInput';

function Form() {
  const ref = useRef(null);

  // ref.current = { focus, clear }
  // NOT the raw <input> DOM node

  return (
    <>
      <FancyInput ref={ref} />
      <button onClick={() => ref.current.focus()}>
        Focus
      </button>
      <button onClick={() => ref.current.clear()}>
        Clear
      </button>
    </>
  );
}
Without vs with
✕ Without
  • ✕Parent holds a ref to the raw DOM node
  • ✕Exposes every DOM method & property — .value, .style, .dataset…
  • ✕Internal structure is locked in — rename the element and the parent breaks
✓ With
  • ✓Parent holds a ref to your custom object
  • ✓Only focus and clear are visible — nothing else leaks
  • ✓Child can refactor internals freely without breaking the parent
When to use it
✓ Good fits
Focus / blur control Scroll into view Play / pause media Reset form field Trigger animation Headless component API Measure layout
✕ Use state / props instead
Syncing data upward Passing config down Conditional rendering Reading child values Event handling
If you can solve it with props & state, do that. Refs are an escape hatch for things React can't model declaratively.
Deps array — three patterns
Omit
useImperativeHandle(ref, () => ({
  fn
}));
Recreates on every render. Fine for static methods that don't close over changing values.
Empty []
useImperativeHandle(ref, () => ({
  fn
}), []);
Creates once on mount. Use only if the factory closes over nothing that can change.
[value]
useImperativeHandle(ref, () => ({
  fn
}), [value]);
Recreates when value changes. Most correct when the factory captures state or props.

Here's your 5-minute cheatsheet. Key things to remember: **The one-liner:** `useImperativeHandle` lets a child component control exactly what a parent gets when it holds a `ref` — instead of the raw DOM node, the parent sees a curated API you define. **Three things always required:** `forwardRef` on the component, the forwarded `ref` as the second argument, and calling `useImperativeHandle(ref, factory, deps)` inside. **When to reach for it:** Triggering imperative actions (focus, play, scroll, reset) from a parent. If you're tempted to use it for data flow, use state and props instead. The React 19 section covers the new syntax where `forwardRef` is dropped entirely and `ref` arrives as a plain prop.

React 19 update
React 19+
forwardRef is now unnecessary — ref is passed as a plain prop. Everything else stays the same.
// React < 19
const FancyInput = forwardRef((props, ref) => { ... });

// React 19 — ref is just a prop now
function FancyInput({ ref, ...props }) {
  useImperativeHandle(ref, () => ({
    focus() { inputRef.current.focus(); },
  }));
  return <input ref={inputRef} />;
}
How to implement it — 4 steps
1
Create an inner ref with useRef(null) inside the child to hold the actual DOM node.
2
Wrap the component in forwardRef((props, ref) => …) so the parent's ref reaches inside.
3
Call the hook — useImperativeHandle(ref, factory, deps) — and return only the methods you want to expose.
4
Use from the parent with a normal useRef() and call ref.current.yourMethod() after mount.
