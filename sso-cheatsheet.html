Single Sign-On (SSO)

5-min reference Protocols · Flow · Terms · Examples
What Is SSO?

An authentication scheme where a user logs in once and gains access to multiple apps without re-entering credentials.

  • Identity Provider (IdP) — the central login authority (e.g. Okta, Azure AD, Google)
  • Service Provider (SP) — any app relying on the IdP (Slack, GitHub, Salesforce…)
  • Token / Assertion — cryptographically signed proof of identity passed between IdP ↔ SP
  • Session — once authenticated, a shared session eliminates repeated logins

Protocols Compared
Protocol Format Best For
SAML 2.0 XML assertions Enterprise / legacy web apps
OAuth 2.0 JSON tokens Authorization (not authn) — API access
OIDC JWT on OAuth 2.0 Modern web & mobile SSO (Google, Apple login)
Kerberos Tickets (binary) On-prem Windows / Active Directory
LDAP Directory protocol Internal directory lookup (often paired with above)
Key Terms
IdP (Identity Provider)
The trusted system that authenticates users — e.g. Okta, Azure AD, Google Workspace.
SP (Service Provider)
The app user wants to access — trusts the IdP to vouch for the user.
Assertion / JWT
Digitally signed claim: "this user is who they say they are, with these attributes."
Federation
Extending SSO trust across organizations (e.g. partner company login).
SLO (Single Log-Out)
Logging out of IdP terminates sessions in ALL connected SPs simultaneously.
Benefits & Risks
✓ Benefits
  • One password to manage
  • Fewer phishing targets
  • Central access control
  • Faster onboarding / offboarding
  • Audit logs in one place
✗ Risks
  • Single point of failure
  • IdP breach = all apps compromised
  • Complex setup / misconfiguration
  • Vendor lock-in
  • SLO gaps leave sessions open

Security Best Practices
  • Enforce MFA at the IdP — one layer protects everything
  • Short token lifetimes + refresh tokens reduce breach windows
  • Validate every field in assertions (issuer, audience, expiry)
  • Use HTTPS everywhere; tokens in transit must be encrypted
  • Implement SLO so offboarding revokes all sessions instantly
  • Monitor IdP logs for anomalous login patterns
  • Rotate signing keys periodically and support key rollover
