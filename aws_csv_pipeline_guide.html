AWS Event-Driven CSV Processing Pipeline Setup Guide

Complete Step-by-Step Walkthrough, Code, and Screenshot Checklists

0. IAM User & Sign-In Verification

Before creating resources, ensure you are logged into AWS using your non-root IAM user.

  1. Go to AWS Sign-In Console.
  2. Select IAM user.
  3. Enter your 12-digit Account ID and click Next.
  4. Enter IAM User Name: Assignment and your password.
  5. Verification: Check the top-right corner of the console. It should display:
    Assignment @ [your-account-id]
  6. AWS Region: Keep all resources in the same region (e.g., Europe (Stockholm) eu-north-1).

1. Step-by-Step Resource Setup (Part C)

1.1 Amazon S3 Setup

  1. Open the Amazon S3 Console → Click Create bucket.
  2. Bucket name: Enter a globally unique, lowercase name (e.g., assignment-csv-pipeline-[yourname]).
  3. AWS Region: Select eu-north-1 (Europe - Stockholm).
  4. Keep default settings (Block Public Access ON, Encryption enabled) and click Create bucket.
  5. Click into your new bucket → Click Upload → Add files.
  6. Upload a test CSV dataset (e.g., sample_data.csv).
📸 Screenshot #1 Required: Take a screenshot of the S3 bucket page showing the uploaded CSV object listed under the Objects tab.

1.2 Amazon DynamoDB Setup

  1. Open the Amazon DynamoDB Console → Click Create table.
  2. Table name: FileProcessingMetadata Must match code exactly
  3. Partition key: file_name (Select String).
  4. Leave settings as Default settings (On-Demand capacity).
  5. Click Create table and wait until status becomes Active.

1.3 IAM Role Setup (Created via Root)

Since the Assignment user operates under restricted permissions, create the Lambda execution role via Root user:

  1. Log into AWS as Root user → Open IAM Console → Roles → Create role.
  2. Select AWS service → Lambda → Click Next.
  3. Attach the following policies:
    • AWSLambdaBasicExecutionRole
    • AmazonS3ReadOnlyAccess
    • AmazonDynamoDBFullAccess
  4. Name the role LambdaPipelineRole → Click Create role.
  5. Sign out of Root and sign back in as the Assignment user.

1.4 AWS Lambda Setup

  1. Open the AWS Lambda Console → Click Create function.
  2. Select Author from scratch.
  3. Function name: FileProcessingPipeline
  4. Runtime: Select Python 3.12 (or Python 3.11).
  5. Permissions: Expand Change default execution role → Select Use an existing role → Choose LambdaPipelineRole.
  6. Click Create function.

1.5 Deploy Baseline Python Code

In the Lambda function's Code tab, replace existing code with the following snippet and click Deploy:

import json
import boto3
import datetime
import csv
import io
import os

s3_client = boto3.client('s3')
dynamodb = boto3.resource('dynamodb')
table = dynamodb.Table('FileProcessingMetadata')

def lambda_handler(event, context):
    record = event['Records'][0]
    bucket_name = record['s3']['bucket']['name']
    file_key = record['s3']['object']['key']
    file_size = record['s3']['object']['size']
    file_extension = os.path.splitext(file_key)[1].lower()
    timestamp = datetime.datetime.utcnow().isoformat()
    
    rows = None
    columns = None
    
    if file_extension != '.csv':
        print(f"Unsupported file type: {file_extension}")
        return {"statusCode": 400, "body": "Only CSV files are supported"}
    
    # Download CSV from S3
    response = s3_client.get_object(Bucket=bucket_name, Key=file_key)
    content = response['Body'].read().decode('utf-8')
    
    csv_reader = csv.reader(io.StringIO(content))
    data = list(csv_reader)
    
    rows = len(data) - 1 if len(data) > 1 else 0
    columns = len(data[0]) if data else 0
    
    log_message = {
        "file_name": file_key,
        "file_type": file_extension,
        "file_size_bytes": file_size,
        "rows": rows,
        "columns": columns,
        "processed_at": timestamp
    }
    
    print("Processed File Metrics:", json.dumps(log_message))
    
    # Insert record into DynamoDB
    table.put_item(
        Item={
            "file_name": file_key,
            "processed_at": timestamp,
            "file_type": file_extension,
            "file_size_bytes": file_size,
            "rows": rows,
            "columns": columns
        }
    )
    
    return {
        "statusCode": 200,
        "body": json.dumps(log_message)
    }

1.6 Add S3 Trigger to Lambda

  1. In the Function overview diagram on your Lambda page, click + Add trigger.
  2. Select S3 from the dropdown.
  3. Bucket: Select your created S3 bucket.
  4. Event type: Select All object create events (s3:ObjectCreated:*).
  5. Check the acknowledgment box for recursive invocation risks → Click Add.
