Discrete vs Continuous attributes

Discrete: Countable, finite or countably infinite values. Cannot be fractional. Example: number of children (0, 1, 2, 3...). You cannot have 2.5 children.

Continuous: Can take any value in a range, including decimals. Example: height (1.732m), temperature (36.8°C), weight (72.4kg).

Types of data sets
Record data: Rows and columns. Each row = one object. Most common form.
Ordered data (time-series): Sequential order matters. Stock prices, sensor readings over time.
Graph data: Objects connected by relationships. Molecule structure (atoms + bonds), social networks.
Document data (Bag of Words): Each document = word count vector. News articles, reviews.
Transaction data: Each record = set of items. Supermarket baskets.
02Data Quality
Five dimensions of data quality
Accuracy: Values are correct and reflect reality.
Completeness: No important values are missing.
Consistency: No contradictions within or across datasets.
Timeliness: Data is recorded at the right frequency for the analysis being performed.
Fitness for use: A dataset is "high quality" only relative to its intended purpose. Customer addresses = high quality for delivery, low quality for trend research.
Data quality problems
Noise
Wrong, impossible, or corrupted values. The measurement itself is broken. Examples: Age = 150, Mileage = −999, sq_ft = −100.

Cause: Faulty instruments, transmission errors, data entry mistakes.
Outlier
Real, valid value that is just extreme. The measurement is correct. Example: Elon Musk's net worth in a dataset of average salaries, Bugatti in a fuel efficiency dataset.

Sometimes outliers ARE the goal (fraud detection).
Missing values
Data not collected. Causes: not applicable, forgotten, misunderstood. Risk of ignoring tuples: significant loss of information and bias if missingness is not random.
Inconsistent data
Contradictions within a record or across datasets. Example: Birthday = 2010, Age = 42. Main cause: merging datasets with different standards.
Handle noise FIRST. Noise inflates mean and SD → outlier detection thresholds become wrong → real outliers get missed.
Handling missing values
Ignore the tuple: Delete the row. Risk: information loss and bias in small datasets.
Global constant: Fill with "Unknown", "NA", or "infinity" across the whole dataset.
Mean/median imputation: Replace with attribute average. Simple but ignores relationships.
Most probable value: Use regression or Bayesian inference to predict the missing value. Most sophisticated.
Entity identification problem

When merging datasets, the same real-world entity may appear multiple times with slightly different names or formats. Example: "S Venkatesh", "Venkatesh S", "S. Venkatesh" all referring to the same person = duplicate data problem.

Entity identification problem → always associated with duplicate data, not noise or missing values.
03Sampling Techniques
Simple Random Sampling

SRSWR (With Replacement): After selecting an object, put it back. Same object can be selected more than once.

SRSWOR (Without Replacement): Once selected, removed from pool. Each object can only appear once.

Stratified vs Cluster Sampling
Stratified sampling
Divide into strata (groups with shared characteristics). Sample proportionally from EVERY group. Ensures all groups are represented. Reduces bias.

Example: Divide loan applicants by age (20–30, 31–40, 41–50). Sample randomly from each group.
Cluster sampling
Divide into clusters. RANDOMLY select a few whole clusters. Study EVERYONE in selected clusters. Used for convenience and cost efficiency.

Example: Divide city into 10 districts. Randomly pick 3. Survey every person in those 3.
Stratified = some from everywhere. Cluster = everyone from somewhere randomly chosen.
04Data Preprocessing Pipeline
Knowledge Discovery in Databases (KDD) process

Raw Data → Data Cleaning → Data Integration → Data Selection → Data Transformation → Data Mining → Pattern Evaluation → Knowledge

Data Transformation's role: a crucial preprocessing step that bridges the gap between raw data and the data mining stage. Not the first step, not the last — it prepares data for mining.
Data Aggregation

Combining multiple records into summary statistics. Example: daily sales → monthly sales totals.

Key benefit: Aggregated data tends to have less variability — it smooths out noise. A single sale might be unusual; monthly totals show stable trends.

Data Compression: lossy vs lossless

Lossless: Original data can be perfectly reconstructed. Example: ZIP file, PNG image.

Lossy: Some information is permanently lost. Example: JPEG photograph (some pixel detail discarded), Forward Selection (discarded features cannot be recovered).

05Normalization Methods
Min-Max Normalization
X' = (X − Xmin) / (Xmax − Xmin) To scale to [new_min, new_max]: X' = ((X − Xmin)/(Xmax − Xmin)) × (new_max − new_min) + new_min

Maps all values to [0, 1] by default. Minimum becomes 0, maximum becomes 1.

Avoid when data has many significant outliers. One extreme value compresses all others into a tiny range.
Z-Score Normalization
Z = (X − Mean) / SD SD = √(Σ(X − Mean)² / N)

Centers data at 0 with SD of 1. No fixed range output.

Preferred over Min-Max when data has outliers or different distributions. Robust because it uses SD not range.
Decimal Scaling
X' = X / 10^j where j = smallest integer such that max|X'| < 1

Simply shifts the decimal point. Find j by looking at maximum absolute value.

Example: max value = 50 → 50/100 = 0.5 < 1, so j = 2. Divide everything by 100.

Worked example — full normalization

Dataset sorted: 1, 2, 3, 4, 8, 11, 15, 24, 36, 42, 49, 50

Min-Max (Xmin=1, Xmax=50, denominator=49): 1→0.00, 2→0.02, 3→0.04, 4→0.06, 8→0.14 11→0.20, 15→0.29, 24→0.47, 36→0.71 42→0.84, 49→0.98, 50→1.00 Decimal Scaling (j=2, divide by 100): 0.01, 0.02, 0.03, 0.04, 0.08, 0.11, 0.15, 0.24, 0.36, 0.42, 0.49, 0.50
06Binning (Smoothing)
What is binning?

Binning groups sorted values into equal-sized buckets (bins) and replaces each value with a representative of its bin. Used to reduce noise by smoothing local fluctuations.

Always sort data first before binning. This is a required step — never skip it.
Mean Binning vs Boundary Binning

Dataset: {8,15,49,3,24,2,36,11,1,42,4,50} → sorted: 1,2,3,4,8,11,15,24,36,42,49,50

3 bins × 4 values: Bin1=[1,2,3,4] Bin2=[8,11,15,24] Bin3=[36,42,49,50]

Mean Binning — replace with bin mean: Bin1 mean=2.5 → [2.5, 2.5, 2.5, 2.5] Bin2 mean=14.5 → [14.5,14.5,14.5,14.5] Bin3 mean=44.25→ [44.25,44.25,44.25,44.25] Boundary Binning — replace with nearest boundary: Bin1 [min=1, max=4]: 1→1, 2→1, 3→4, 4→4 Bin2 [min=8, max=24]: 8→8, 11→8, 15→8*, 24→24 Bin3 [min=36, max=50]: 36→36, 42→36, 49→50, 50→50 *15: dist to 8=7, dist to 24=9 → closer to 8
07Attribute Subset Selection
Why reduce attributes?

Irrelevant and redundant features slow down learning, reduce model accuracy, and cause overfitting. Attribute selection finds the minimal set that still predicts well.

Heuristic search methods
Forward Selection: Start with no features. Add one at a time — keep if it improves accuracy. Stop when no improvement. Lossy — discarded features are gone permanently.
Backward Elimination (Stepwise Attribute Elimination): Start with all features. Remove one at a time — remove if accuracy doesn't drop. Also lossy.
Optimal Branch and Bound: Backtracking approach. Explores subsets systematically. More thorough than greedy methods but computationally expensive.
Decision Tree Induction: Build a tree using all features. Branches that don't appear = irrelevant features. Pruned automatically.
Lossy = information permanently lost, cannot reconstruct original. Lossless = original fully recoverable.
08Similarity Measures: SMC and Jaccard
Binary similarity problem setup

Two objects (patients, documents, transactions) described by binary features (0 = absent, 1 = present). How similar are they?

f11 = both have it (1,1) f00 = both lack it (0,0) f10 = A has it, B doesn't (1,0) f01 = B has it, A doesn't (0,1)
SMC and Jaccard formulas
SMC = (f11 + f00) / (f11 + f00 + f10 + f01) Jaccard = f11 / (f11 + f10 + f01)

Key difference: SMC counts "both absent" (f00) as a match. Jaccard completely ignores f00.

Why Jaccard ignores f00: Absence of a feature does not prove similarity. If two patients both lack 900 out of 1000 symptoms, that tells us nothing about their shared condition.

SMC ≥ Jaccard always. Use Jaccard for medical, transactional, or any data where absence is meaningless.
Worked example

Two patients: Fever(1,1), Cough(1,0), Headache(0,0), Fatigue(1,1) → f11=2, f00=1, f10=1, f01=0

SMC = (2+1)/(2+1+1+0) = 3/4 = 0.75 Jaccard = 2/(2+1+0) = 2/3 = 0.67
09Outlier Detection Methods
DBSCAN vs Local Outlier Factor (LOF)
DBSCAN
Density-based clustering. Points in low-density regions or far from any cluster = outliers. Global approach — outlier is defined relative to all clusters.
LOF (Local Outlier Factor)
Scores each point based on how its local density compares to its neighbors' density. A point is an outlier if it is much less dense than its surroundings. Local approach — captures contextual outliers.
01Feature Engineering Fundamentals
What is feature engineering?

The process of using domain knowledge to create, transform, select, or encode raw data into features that make machine learning models learn better and faster.

Raw data is rarely model-ready. Feature engineering bridges that gap.

Four types of feature engineering
Feature Creation: Build new features from existing ones. Example: Date of Birth → Age. Timestamp → Hour of Day. Price × Quantity → Revenue.
Feature Transformation: Change the scale or distribution of a feature. Example: Log transformation for skewed data. Z-score normalization. Min-max scaling.
Feature Selection: Remove irrelevant or redundant features. Keeps the model lean and prevents overfitting.
Feature Encoding: Convert categorical data into numeric form. Example: One-hot encoding, ordinal encoding, label encoding.
Curse of dimensionality

As the number of features grows, the data becomes increasingly sparse. In high-dimensional space, distances between all points become nearly equal — distance metrics lose meaning. Models overfit, training slows.

Solution: dimensionality reduction (PCA) or feature selection to remove redundant features.
02Encoding Categorical Variables
Ordinal vs One-Hot Encoding
Ordinal encoding
Assigns integers 1, 2, 3... to categories. Use ONLY when genuine order exists. Example: Low=1, Medium=2, High=3.

Danger: implies mathematical relationship between categories.
One-hot encoding
Creates a binary column for each category. Each row gets a 1 in its category column and 0 elsewhere. No false ordering implied.

Use when categories have no natural order. Example: Loan_Purpose with 17 categories.
Never use ordinal encoding for nominal categories like Loan_Purpose, Color, City. The implied order misleads the model.
03Transformations for Skewed Data
Right-skewed data problem

Right skew = a few very large values pull the distribution to the right. Most values are clustered low, with a long tail extending right. Example: income, house prices, loan amounts.

Problem: Models sensitive to scale (linear regression, KNN, logistic regression) are confused by the extreme spread. Predictions are dominated by extreme values.

Log transformation
X' = log(X) or X' = log(X + 1) [if X can be 0]

Compresses large values dramatically while leaving small values relatively unchanged. A salary of ₹500,000 becomes log(500,000) ≈ 13. A salary of ₹30,000 becomes log(30,000) ≈ 10. The gap shrinks from 470,000 to just 3.

Also reduces heteroscedasticity — the problem where variance of residuals increases with fitted values (funnel shape in residual plots).

Log transformation = squish the tail. Makes right-skewed data more symmetric and easier for models.

04Feature Selection
Why select features?

Irrelevant features add noise. Redundant features carry the same information twice. Both slow training, reduce accuracy, and increase overfitting risk.

Feature selection = find the minimum set of features that maximizes model performance.

Filter methods

Evaluate features independently of any model. Fast but ignores feature interactions.

Correlation (Pearson): For continuous features vs continuous target. Measures linear relationship.
Chi-square test: For categorical features vs categorical target. Tests statistical independence.
Mutual information: Measures information shared between feature and target.
Wrapper methods

Use model performance as the selection criterion. Slower but more accurate.

Sequential Forward Selection: Start with no features. Add one at a time based on performance gain. Lossy.
Backward Elimination: Start with all features. Remove one at a time. Lossy.
Ridge regression (L2): Shrinks coefficients toward zero but never exactly to zero. Does NOT eliminate features.
Lasso regression (L1): Can shrink coefficients exactly to zero. DOES eliminate features.
Ridge = L2 = squishes but keeps all features. Lasso = L1 = can zero out features = performs selection.
05Text Feature Engineering
Bag of Words (BoW)

Represents each document as a vector of word counts. Vocabulary = all unique words across all documents. Each document gets a count per word.

Limitation: Ignores word order ("not good" = same tokens as "good not"). Cannot capture meaning. Creates sparse, high-dimensional vectors.

TF-IDF
TF-IDF(word, doc) = TF(word, doc) × IDF(word) TF = count of word in doc / total words in doc IDF = log(total docs / docs containing word)

TF rewards words that appear frequently in a specific document. IDF penalizes words that appear in almost every document (like "the", "is"). Result: rare, informative words get high scores.

TF-IDF is always better than raw BoW for text classification. Use it by default.
Word Embeddings

Represent each word as a dense vector of real numbers (e.g. 300 dimensions) that captures semantic meaning.

Word2Vec: Learns embeddings by predicting context words from target (or vice versa). Uses local context windows.

GloVe: Uses global word co-occurrence statistics from the entire corpus. Better at capturing global meaning relationships.

GloVe vs Word2Vec: GloVe = global co-occurrence. Word2Vec = local context windows.
NLP concepts
POS tagging: Assigns grammatical roles to words — Noun, Verb, Adjective, etc.
Unigrams: Single tokens (one word at a time).
Bigrams: Pairs of consecutive words. Fixes "not good" misclassification problem.
Bag of Words limitation: Cannot capture semantics or word order. Produces sparse vectors.
06Time-Series and Sensor Features
Time-derived features from timestamps
Hour of day: Captures daily cycles (temperature peaks at noon, dips at night).
Day of week: Weekday vs weekend patterns (occupancy, heating load).
Month / season: Seasonal temperature patterns.
Lag features: Previous timestamp's value. Most powerful predictor for sensor data — temperature at T−1 predicts temperature at T.
Rolling statistics: Mean or SD over last N timestamps. Captures trends and volatility.
For time-series prediction: lag features + rolling averages + hour of day = the winning combination in most cases.
Interaction features

Create new features by combining two existing ones. Captures relationships that neither feature alone can express.

Example: Motion_Flag × Temperature. When Motion=1 (people present), body heat affects room temperature. This interaction tells the model something neither feature alone can.

07Audio Feature Engineering
Features extracted from audio
MFCC (Mel-Frequency Cepstral Coefficients): Captures how frequency content changes over time. Mimics human auditory perception. Most important feature for speech recognition.
Spectrogram: 2D representation of frequency vs time. Shows which frequencies are present when. Can be fed to CNNs as an image.
Zero Crossing Rate: How often the waveform crosses zero amplitude. High for noisy/percussive sounds, low for smooth tones.
RMS Energy: Root mean square of amplitude over a window. Captures loudness patterns.
Chroma features: Represent the 12 pitch classes in music. Useful for chord and key detection.
Raw waveform training — when possible?
Yes — deep learning
CNNs, RNNs, Transformers can learn features automatically from raw waveforms. Examples: WaveNet, wav2vec, Whisper. Requires large datasets.
No — traditional ML
SVM, Random Forest, KNN need fixed-length numeric feature vectors. Cannot process raw sequences. Always need hand-crafted features (MFCCs etc.) first.
08Automated Feature Engineering
Tools and methods
Featuretools / Deep Feature Synthesis (DFS): Recursively aggregates and transforms features across related entities (relational data). Automatically creates complex features.
TSFresh: Extracts hundreds of time-series features automatically. Uses hypothesis testing to filter out irrelevant ones.
FeatureWiz: Selects and ranks important features using model-based importance and correlation filtering.
Permutation Feature Importance: Model-agnostic. Shuffles one feature at a time and measures performance drop. Features that hurt performance most when shuffled = most important.

01Linear Regression
Simple and Multiple Linear Regression
Simple: Ŷ = β₀ + β₁X Multiple: Ŷ = β₀ + β₁X₁ + β₂X₂ + ... + βₖXₖ + ε Least squares estimator: B = (XᵀX)⁻¹ XᵀY

β₀ (intercept): Expected value of Y when all X = 0.

β₁ (slope, simple regression): Expected change in Y for a one-unit increase in X.

β₁ (partial slope, multiple regression): Expected change in Y for a one-unit increase in X₁, holding all other variables constant. The "holding constant" phrase is critical.

LINE assumptions
L — Linearity: Relationship between X and Y is linear.
I — Independence: Errors are not correlated with each other.
N — Normality: Residuals follow a normal distribution.
E — Equal variance (homoscedasticity): Spread of errors is constant across all fitted values.
Funnel shape in residual vs fitted plot = E violated (heteroscedasticity). Fix: log transformation of Y.
R², Adjusted R², and VIF

R²: Proportion of variance in Y explained by the model. R²=0.9 → model explains 90% of variation. R² always increases when you add more predictors — even useless ones.

Adjusted R²: Penalizes for adding unnecessary predictors. Only increases if new predictor genuinely improves the model. Use this when comparing models with different numbers of features.

VIF (Variance Inflation Factor): Detects multicollinearity. VIF > 10 = highly collinear, consider removing. Symptom of severe multicollinearity: significant overall F-test but insignificant individual t-tests.

Large gap between R² and Adjusted R² = model has predictors with little explanatory power. Trim them.
02Logistic Regression
Why not linear regression for binary outcomes?

Linear Probability Model (LPM) applies OLS to a binary dependent variable. Major flaw: it can predict probabilities outside [0,1] — a probability of 1.3 or −0.2 is meaningless.

Logit and Probit models use a non-linear S-shaped function to constrain probabilities between 0 and 1. Both typically yield very similar practical results.

Log-odds, odds, and odds ratios
Odds = P(event) / P(no event) If P = 0.75 → Odds = 0.75/0.25 = 3 Log-odds = ln(Odds) Logistic coefficient = change in log-odds per unit increase in X Odds ratio = e^coefficient

Odds ratio of 2.5: One-unit increase in X multiplies the odds of the event by 2.5.

Odds ratio of 0.90: One-unit increase in X → 10% decrease in the odds.

Coefficient of −0.2 for Income: Higher income decreases the log-odds (and thus odds) of default.

To get odds ratio from logit coefficient: exponentiate it. e^coefficient = odds ratio.
03Hypothesis Testing
Core logic of hypothesis testing

H₀ (null hypothesis): The default assumption. No effect, no difference, no relationship.

H₁ (alternative hypothesis): What you are trying to prove.

p-value: Probability of seeing this result (or more extreme) if H₀ were true. Small p = surprising result = evidence against H₀.

α (significance level): Your threshold. Usually 0.05. If p < α → reject H₀. If p > α → fail to reject H₀.

Never say "accept H₀." Always say "fail to reject H₀." And never say "prove" — statistics gives evidence, not proof.
p-value = 0.08 at α = 0.05 → fail to reject H₀. 0.08 > 0.05.
Choosing the right test

Stratification is NOT one of the 3 experimental design principles. The 3 are: Randomization, Replication, Control.
Chebyshev's inequality
P(|X − μ| ≤ k·σ) ≥ 1 − 1/k²

Works for ANY distribution — no normality assumption needed.

Example: Mean=500g, SD=20g, interval 460–540g. Range = ±40 = ±2σ. So k=2.

1 − 1/k² = 1 − 1/4 = 0.75 = at least 75%
Chebyshev gives a lower bound — "at least X%." Normal distribution gives exact percentages. Chebyshev is more general.
Central Limit Theorem

Take many independent random samples of size n from any population. The distribution of sample means will be approximately normal with:

Mean of sample means = population mean (μ) SD of sample means = σ/√n (standard error)

This holds regardless of the original population's shape — as long as n is large enough (typically n ≥ 30).

04ANOVA
One-way ANOVA

Tests whether means of 3+ groups differ. H₀: all group means are equal. H₁: at least one mean is different.

F-statistic = variance between groups / variance within groups. Large F = groups are more different than random variation would suggest.

ANOVA tells you something is different. Pairwise t-tests (post-hoc) tell you which specific pairs differ.
Two-way ANOVA

Tests effect of two factors simultaneously plus their interaction.

Interaction effect: The effect of Factor A depends on the level of Factor B. Example: Glass packaging is better at low temperature but worse at high temperature vs plastic. You cannot interpret main effects alone if interaction is significant.

Significant interaction = interpreting main effects alone is misleading. Always check interaction first.

06PCA and Factor Analysis
PCA — Principal Component Analysis

Finds new uncorrelated axes (principal components) that capture maximum variance. Projects data from high dimensions to fewer dimensions.

Key properties: Components are orthogonal (completely uncorrelated). PC1 captures most variance, PC2 next most, and so on.

Kaiser criterion: Retain components with eigenvalue > 1. A component below 1 explains less than a single original variable.

Why standardize before PCA: PCA is scale-sensitive. Large-scale variables dominate. Standardize so all variables contribute equally.

PCA vs Factor Analysis: PCA explains total variance (including noise). Factor Analysis explains common variance (shared across variables) and uncovers latent factors.

Factor Analysis

Discovers hidden (latent) factors that explain correlations among observed variables.

Example: Three survey questions "Are you happy?", "Are you satisfied?", "Was your service joyful?" all correlate because they share a latent factor: customer satisfaction.

Factor loadings: Correlation between an observed variable and a latent factor. High loading = this variable strongly reflects this factor.

Condition for factor analysis: Sufficient sample size (5–10 observations per variable), variables should be continuous, sufficient correlations among variables.

Factor analysis does NOT require a dependent variable to be established first. That is NOT one of its conditions.
07Cluster Analysis
Clustering fundamentals

Unsupervised learning. No labels. Goal: group similar objects together.

Good clustering: High intra-cluster similarity (similar within groups) and low inter-cluster similarity (different between groups).

Why standardize before clustering: Distance measures are sensitive to scale. A variable in thousands will dominate distances over a variable in units.

K-Means algorithm

1. Choose K. Place K random centroids. 2. Assign each point to nearest centroid. 3. Update each centroid to mean of its assigned points. 4. Repeat until stable.

Weakness: Sensitive to initial random centroid placement. Different runs can give different results.

Choose K using: Elbow method (find kink in inertia curve) or Silhouette score (maximize average score).

K-Means advantage: Fast, scales to large data (10,000+ points). Use K-Means for big datasets.
Hierarchical clustering

Agglomerative (bottom-up): Each point starts as its own cluster. Merge the two closest clusters. Repeat until one cluster remains. Output = dendrogram.

No need to specify K in advance — cut the dendrogram at any height to get desired number of clusters.

Find optimal K: Look for the largest gap between successive merge distances in the dendrogram.

Linkage methods:

Single linkage: Distance = closest points between clusters. Can create chain-like clusters.
Complete linkage: Distance = farthest points between clusters. Creates compact, spherical clusters.
Ward's linkage: Minimizes total within-cluster variance. Generally produces the most useful clusters.
Hierarchical advantage: no need to specify K, full merge history visible. Disadvantage: slow for large N (O(n²)).
08Time Series Analysis
Components of time series
Trend: Long-term underlying direction (upward or downward).
Seasonal: Predictable pattern that repeats every year (or fixed period). Monthly data → period = 12.
Cyclical: Business cycle fluctuations over several years (expansion and recession). Different from seasonal — no fixed period.
Irregular: Random, unpredictable noise.
Autocorrelation: Correlation of a variable with its own past values over time.
Additive vs multiplicative models
Additive: Y = Trend + Seasonal + Irregular Multiplicative: Y = Trend × Seasonal × Irregular

Additive: Use when seasonal variations are roughly constant regardless of trend level.

Multiplicative: Use when seasonal fluctuations grow proportionally as the trend increases.

Forecasting methods
Moving average: Smooths noise to reveal trend. Large window = smoother but lags behind trend changes.
Simple Exponential Smoothing (SES): Weighted average giving more weight to recent values. High α = very responsive. Best for data with NO trend or seasonality. Produces a flat line forecast.
Holt's method: Extends SES with a trend component (α + β). Handles trend, not seasonality.
Holt-Winters: Extends Holt's with a seasonal component (α + β* + γ). Handles both trend AND seasonality. γ controls seasonal smoothing.
SES = flat forecast. Holt = trend line. Holt-Winters = trend + seasonal waves.
09Maximum Likelihood Estimation
MLE fundamentals

Find the parameter value that makes the observed data most likely to have occurred.

Likelihood: L(p) = C × p^k × (1−p)^(n−k) Log-likelihood: l(p) = ln(C) + k·ln(p) + (n−k)·ln(1−p) MLE: set dl/dp = 0 and solve → p̂ = k/n

Example: 20 coin flips, 5 heads → MLE for P(heads) = 5/20 = 0.25

Why log-likelihood: Products become sums. Mathematically simpler. Same answer (log is monotonic).

Properties of MLE
Consistency: As sample size grows, MLE converges to the true parameter value.
Efficiency: In large samples, MLE has the smallest possible variance among good estimators.
Asymptotic normality: In large samples, MLE is approximately normally distributed — allows confidence intervals and hypothesis tests.
Invariance: MLE of f(θ) = f(MLE of θ). If MLE of σ² = 16, then MLE of σ = √16 = 4.
Invariance is the most exam-tested property: always take the function of the estimate, not the other way around.
10Bayesian Inference
Bayesian framework
Posterior ∝ Likelihood × Prior P(θ|Data) ∝ P(Data|θ) × P(θ)

Prior P(θ): Your belief about the parameter before seeing data. Uninformative prior = let data speak.

Likelihood P(Data|θ): How well the parameter explains the observed data.

Evidence P(Data): Marginal likelihood — normalizing constant.

Posterior P(θ|Data): Updated belief after combining prior with evidence. The final result of Bayesian analysis.

Bayesian updating (worked example)

Machine 1: P(M1)=0.30, P(defective|M1)=0.25. Machine 2: P(M2)=0.70, P(defective|M2)=0.05

P(defective) = 0.25×0.30 + 0.05×0.70 = 0.075 + 0.035 = 0.110 P(M1|defective) = (0.25×0.30)/0.110 = 0.075/0.110 ≈ 0.682 Second defective board (use 0.682 as new prior): P(defective) = 0.25×0.682 + 0.05×0.318 = 0.1705+0.0159 = 0.1864 P(M1|both defective) = (0.25×0.682)/0.1864 ≈ 0.915
Each new piece of evidence updates your belief. Two defective boards in a row makes Machine 1 extremely likely (91.5%).
Frequentist CI vs Bayesian credible interval

Frequentist 95% CI: "If we repeated this experiment 100 times, 95 of those confidence intervals would contain the true parameter." You cannot say the parameter is in THIS interval with 95% probability.

Bayesian 95% credible interval: "Given the data, there is a 95% probability that the true parameter lies in this range." Direct probability statement about the parameter.

Bayesian credible interval says exactly what most people intuitively want — but frequentist CI technically cannot say this.
